# CVAE for Contact Configuration Distribution

This implementation learns the conditional distribution `p(Δq_contact | q_0, x_idx)` using a Conditional Variational Autoencoder (CVAE) with concat conditioning.

## Files

- **`cdf_dataloader.py`**: Dataset and DataLoader for training
  - Implements distance-scaled sampling strategy (距离放缩采样)
  - Loads `.pt` format data from `cdf.generate_data()`
  
- **`CVAE.py`**: CVAE model implementation
  - Concat conditioning: Encoder([Δq, c]) and Decoder([z, c])
  - Standard Gaussian prior: p(z) = N(0, I)
  
- **`q_CVAE.py`**: Training and testing script
  - Training loop with loss monitoring
  - Visualization of sampled configurations
  - Evaluation metrics

## Usage

### 1. Generate Training Data

First, ensure you have the data file `data22.pt` generated by running:

```python
from cdf import CDF2D
import torch

device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
cdf = CDF2D(device)
cdf.generate_data(nbDiscretization=50)
```

This creates a file with shape `(50, 50, 200, 2)` containing contact configurations for each grid point in workspace.

### 2. Train the CVAE Model

```bash
cd /home/hefei/cdf/multi-dir

# Basic training
python q_CVAE.py --data_path ../2Dexamples/data22.pt \
                 --epochs 100 \
                 --batch_size 128 \
                 --lr 1e-3

# With custom parameters
python q_CVAE.py --data_path ../2Dexamples/data22.pt \
                 --num_joints 2 \
                 --latent_dim 32 \
                 --hidden_dims 256 128 \
                 --gamma 0.5 \
                 --samples_per_grid 10 \
                 --epochs 200 \
                 --batch_size 128 \
                 --lr 1e-3 \
                 --beta 1.0 \
                 --save_path ./checkpoints/cvae_model.pth
```

### 3. Key Parameters

#### Data Parameters:
- `--data_path`: Path to `.pt` data file (default: `../2Dexamples/data22.pt`)
- `--num_joints`: Configuration space dimension (default: 2)
- `--gamma`: Distance scaling factor for sampling (default: 0.5)
  - Controls the range of valid contact configs: `||q_i - q_min|| <= (1+gamma)||q_min - q_0||`
- `--samples_per_grid`: Training samples per workspace grid point (default: 10)

#### Model Parameters:
- `--latent_dim`: Latent space dimension (default: 32)
- `--hidden_dims`: Hidden layer sizes (default: [256, 128])

#### Training Parameters:
- `--batch_size`: Batch size (default: 128)
- `--epochs`: Number of epochs (default: 100)
- `--lr`: Learning rate (default: 1e-3)
- `--beta`: KL divergence weight (default: 1.0)
  - β=1.0: standard VAE
  - β<1.0: β-VAE (prioritize reconstruction)
  - β>1.0: prioritize regularization

### 4. Inference

```python
import torch
from CVAE import CVAE

# Load trained model
device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
checkpoint = torch.load('./checkpoints/cvae_model.pth')
model = CVAE(data_dim=2, condition_dim=4, latent_dim=32, hidden_dims=[256, 128])
model.load_state_dict(checkpoint['model_state_dict'])
model.to(device)
model.eval()

# Sample contact configurations
q_0 = torch.tensor([0.5, -0.3]).to(device)  # Initial config
x_idx = torch.tensor([1.0, 2.0]).to(device)  # Target workspace point
condition = torch.cat([q_0, x_idx], dim=0)

# Generate multiple samples
with torch.no_grad():
    delta_q_samples = model.sample(condition, n_samples=50)  # (50, 2)
    q_contact_samples = q_0 + delta_q_samples
    
print(f"Sampled contact configurations: {q_contact_samples.shape}")
```

## Distance-Scaled Sampling Strategy (距离放缩采样)

Given `q_0` and candidate set `Q_idx`:

1. Find nearest config: `q_min = argmin_{q_i in Q_idx} ||q_i - q_0||`
2. Define threshold: `d_thresh = (1 + γ) * ||q_min - q_0||`
3. Sample from: `{q_i | ||q_i - q_min|| <= d_thresh}`

**Intuition**: 
- Sample configs that are "near" the optimal contact config
- γ controls the diversity of training samples
- Larger γ → more diverse but potentially less accurate samples

## Model Architecture

```
Encoder:
  Input: [Δq, q_0, x_idx] → (data_dim + condition_dim,)
  Hidden: [256, 128] with ReLU + BatchNorm
  Output: μ, logσ² → (latent_dim,) each

Decoder:
  Input: [z, q_0, x_idx] → (latent_dim + condition_dim,)
  Hidden: [128, 256] with ReLU + BatchNorm
  Output: Δq_recon → (data_dim,)
```

## Loss Function

```
L = E[||Δq_recon - Δq||²] + β * KL(N(μ, σ²) || N(0, I))
  = Reconstruction Loss + β * KL Divergence
```

Where:
- Reconstruction: MSE between predicted and true Δq
- KL Divergence: Regularization term enforcing N(0, I) prior

## Tips for Better Performance

1. **Data quality**: Ensure `generate_data()` produces diverse contact configs
2. **Gamma tuning**: Start with γ=0.5, increase if need more diversity
3. **Beta scheduling**: Consider β-annealing (start low, increase gradually)
4. **Latent dimension**: Increase if modeling complex multimodal distributions
5. **Hidden layers**: Deeper networks for high-dimensional config spaces

## Troubleshooting

### Issue: Poor sample quality
- Increase `latent_dim` and/or `hidden_dims`
- Reduce `beta` to prioritize reconstruction
- Increase `gamma` for more diverse training data

### Issue: Mode collapse
- Increase `beta` to encourage exploration
- Use conditional prior instead of standard Gaussian
- Increase `samples_per_grid` for more training data

### Issue: Training instability
- Reduce learning rate
- Use gradient clipping
- Check data preprocessing (normalize inputs)

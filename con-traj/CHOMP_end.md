本文提出了一种**基于约束轨迹优化的操作规划方法**，旨在处理目标集合（goal sets）问题，扩展了原有的 CHOMP（Covariant Hamiltonian Optimization for Motion Planning）算法，使其能够处理**目标集约束**（即仅影响轨迹终点的约束），并在此基础上推广到更一般的轨迹约束。以下是对所提方法的详细整理，包括公式、符号说明及其几何意义。

## 一、问题建模与目标函数

### 1. 轨迹表示

设轨迹 $\xi : [0,1] \to \mathbb{Q}$ 是从时间到机器人构型空间的映射，其中 $\mathbb{Q} \subset \mathbb{R}^d$ 。在实际实现中，轨迹被离散化为：
$\xi \approx (q_1^T, q_2^T, \ldots, q_n^T)^T \in \mathbb{R}^{n \times d}$

### 2. 目标函数

CHOMP 的目标函数由两部分组成：
$\mathcal{U}[\xi] = \lambda f_{\text{prior}}[\xi] + f_{\text{obs}}[\xi]$

- $f_{\text{prior}}[\xi]$：平滑性先验，通常为速度平方的积分：
$f_{\text{prior}}[\xi] = \frac{1}{2} \int_0^1 \|\xi'(t)\|^2 dt$
在离散形式下可写为：
$f_{\text{prior}} = \frac{1}{2} \|K\xi + e\|^2 = \frac{1}{2} \xi^T A \xi + \xi^T b + c$
其中 $K$为有限差分矩阵， $e$ 为边界项， $A = K^T K$ 是**平滑度度量矩阵**。
- $f_{\text{obs}}[\xi]$ ：障碍物代价，衡量机器人身体点在轨迹中扫过的区域与障碍物的接近程度：
$f_{\text{obs}}[\xi] = \int_0^1 \int_{\mathcal{B}} c(x(\xi(t), u)) \left\| \frac{d}{dt} x(\xi(t), u) \right\| du dt$
其中：
    - $\mathcal{B}$ ：机器人身体点集；
    - $x(q, u)$ ：正运动学映射；
    - $c(\cdot)$ ：工作空间代价函数。

---

## 二、无约束 CHOMP 的更新规则

在离散形式下，CHOMP 的迭代更新为：
$\xi_{t+1} = \xi_t - \frac{1}{\eta_t} A^{-1} g_t$

- $g_t$ ：目标函数的离散梯度；
- $\eta_t$ ：步长参数；
- $A^{-1}$ ：平滑算子，将梯度沿轨迹传播。

该更新规则来源于以下带信任域的优化问题：
$\xi_{t+1} = \arg\min_{\xi} \mathcal{U}(\xi_t) + g_t^T (\xi - \xi_t) + \frac{\eta_t}{2} \|\xi - \xi_t\|_A^2$

---

## 三、引入一般轨迹约束

### 1. 约束建模

设约束函数为 $h: \Xi \to \mathbb{R}^k$ ，要求 $h(\xi) = 0$ 。线性化近似为：
$h(\xi) \approx h(\xi_t) + C(\xi - \xi_t) = C(\xi - \xi_t) + b$

- $C = \frac{\partial h}{\partial \xi}(\xi_t)$ ：约束的 Jacobian；
- $b = h(\xi_t)$ ：当前轨迹的约束误差。

### 2. 带约束的更新问题

$\begin{aligned}
\xi_{t+1} = \arg\min_{\xi} &\ \mathcal{U}(\xi_t) + g_t^T (\xi - \xi_t) + \frac{\eta_t}{2} \|\xi - \xi_t\|_A^2 \\
\text{s.t.} &\ h(\xi) = 0
\end{aligned}$

等价于：
$\xi_{t+1} = \arg\min_{\xi} \|\xi_t - \frac{1}{\eta_t} A^{-1} g_t - \xi\|_A^2, \quad \text{s.t.} \ h(\xi) = 0$
即：**先取无约束步，再在 A 度量下投影回约束集**。

### 3. 拉格朗日求解

构造拉格朗日函数：
$\mathcal{L}_g(\xi, \lambda) = \mathcal{U}(\xi_t) + g_t^T (\xi - \xi_t) + \frac{\eta_t}{2} \|\xi - \xi_t\|_A^2 + \lambda^T (C(\xi - \xi_t) + b)$

由一阶最优性条件解得：
$\xi = \xi_t - \frac{1}{\eta_t} A^{-1} g_t - A^{-1} C^T \gamma$
其中 $\gamma = \frac{\lambda}{\eta_t}$ ，代入约束条件得：
$\gamma = (C A^{-1} C^T)^{-1} \left( b - \frac{1}{\eta_t} C A^{-1} g_t \right)$

最终更新规则为：
$\xi = \xi_t - \frac{1}{\eta_t} A^{-1} g_t + \frac{1}{\eta_t} A^{-1} C^T (C A^{-1} C^T)^{-1} C A^{-1} g_t - A^{-1} C^T (C A^{-1} C^T)^{-1} b$

---

## 四、几何解释

更新规则可分解为三个步骤：

1. **无约束步**： $\xi_t - \frac{1}{\eta_t} A^{-1} g_t$ ；
2. **投影到零集**：将无约束步投影到 $C(\xi - \xi_t) = 0$ 上；
3. **偏移校正**：将轨迹拉回真实约束面 $C(\xi - \xi_t) + b = 0$ 。

这相当于在 $A$ 度量下进行**两步投影**，确保轨迹满足线性化约束。

---

## 五、目标集约束的特例

### 1. 约束形式

目标集约束仅影响终点：
$h(\xi) = h_n(q_n)$
此时 Jacobian 为：
$C = [0, \ldots, 0, \tilde{C}]$

- $\tilde{C} = \frac{\partial h_n}{\partial q_n}$ ：终点约束的 Jacobian。

### 2. 更新规则简化

设 $B_n$ 为 $A^{-1}$ 的最后 $d$ 行，且 $B_{nn} = \beta I_d$ ，则更新规则简化为：
$\xi_{t+1} = \xi_t - \frac{1}{\eta_t} A^{-1} g_t + \frac{1}{\eta_t \beta} B_n^T \tilde{C}^T (\tilde{C} \tilde{C}^T)^{-1} \tilde{C} B_n g_t + \frac{1}{\beta} B_n \tilde{C}^T (\tilde{C} \tilde{C}^T)^{-1} b$

### 3. 几何意义

- 终点修正量来自 $\tilde{C}^T (\tilde{C} \tilde{C}^T)^{-1} \tilde{C} B_n g_t$ ，即**在构型空间中对终点进行 Euclidean 投影**；
- 该修正通过 $B_n^T$ 平滑地传播到整个轨迹；
- 传播方式为线性插值： $\Delta q_i = \frac{i}{n} \Delta q_n$ 。

本文在以下任务中验证了所提方法：

- 抓取（易/难起始位姿）
- 手递物体
- 回收任务

实验结果表明：

- 目标集方法在 **88% 场景中平均代价更低**；
- **94% 场景中最佳代价更优**；

- 在某些情况下，由于关节极限或局部极小，算法可能收敛到不可行解；
- 错误的投影方式（如直接在任务空间投影）会导致更差的性能和更长的运行时间。

## 七、结论与展望

本文提出了一个处理目标集约束的轨迹优化框架，核心思想是：

- 在 CHOMP 中引入一般约束；
- 通过线性化和拉格朗日法导出闭式更新；
- 将更新解释为“无约束步 + 投影”；
- 对目标集约束，投影简化为终点构型空间的 Euclidean 投影 + 平滑传播。

未来工作将扩展至：

- 起始集约束；

- 关节极限等其他约束的统一处理；
- 引入探索机制以跳出局部最优。

## 八、新版目标集约束接口（基于距离/评分函数）

### 1. 设计动机

原始接口 `GoalSetConstraint.query()` 直接返回约束残差向量 $h \in \mathbb{R}^k$ 和其 Jacobian $\tilde{C} \in \mathbb{R}^{k \times D}$。这种形式灵活，但对于"到某个目标集的距离"这类最常见的约束，需要手动计算两个量。

新版接口统一抽象为**标量距离（或评分函数）**：

> 子类只需实现 `distance(q_n) -> (d: float, grad_d: ndarray(D,))`
>
> 基类自动推导：$h = [d]$，$\tilde{C} = (\nabla d)^T$，优化器接口不变。

"距离"在此处可以广义理解为任意标量评分函数：值为 0 表示约束满足，值远离 0 表示约束被违反。

### 2. 接口形式

```
class GoalSetConstraint(ABC):
    @abstractmethod
    def distance(q_n) -> (d: float, grad_d: ndarray(D,))

    def query(q_n) -> (h: ndarray(1,), C_tilde: ndarray(1, D))
        # 由基类自动实现：h = [d], C_tilde = grad_d[newaxis, :]
```

优化器（`CHOMPGoalSetOptimizer`）仍调用 `query()`，无需修改。

### 3. 各约束实现迁移说明

| 类名 | 距离函数 $d(q_n)$ | 梯度 $\nabla d$ | 目标集维度 |
|---|---|---|---|
| `TargetPointConstraint` | $\|q_n - q_{\text{goal}}\|$ | $(q_n - q_{\text{goal}}) / \|\cdot\|$ | 0 维（单点） |
| `TargetHyperplaneConstraint` | $n^T q_n - \text{offset}$（有符号） | $n$ | $D-1$ 维（超平面） |
| `TargetRegionConstraint` | $\max(\|q_n - q_{\text{goal}}\| - r,\, 0)$ | $(q_n - q_{\text{goal}}) / \|\cdot\|$（区域外） | $D$ 维（球内区域） |
| `TargetCircleConstraint` | $\|q_n - c\| - r$（有符号） | $(q_n - c) / \|\cdot\|$ | 1 维（圆环） |

### 4. 圆环约束 `TargetCircleConstraint`

圆环约束是本接口的典型测试用例，对应一个**一维目标集**（二维构型空间中的圆弧）。

$$
d(q_n) = \|q_n - c\| - r
$$

$$
\nabla d = \frac{q_n - c}{\|q_n - c\|}
$$

- $d < 0$：终点在圆内；$d > 0$：终点在圆外；$d = 0$：恰好在圆上。
- 优化器可以自由选择**圆上哪个点**作为终点，同时兼顾平滑性与避障代价。
- 这与论文中超平面约束的自由度概念完全一致，只是目标集形状从直线变为圆弧。

几何意义：优化器在每步迭代中，将终点沿径向方向（$\nabla d$）修正，同时通过 $A^{-1}$ 将修正量传播到整条轨迹，保持平滑性。

### 1. 推导过程：从无约束步到带约束的终点修正

这个推导过程是层层递进的，从修改基础，到引入一般约束，最后特化到目标集。

### 第一步：解放终点——修改动力学矩阵 $A$

- **原始 CHOMP 的局限**：在原始 CHOMP 中，轨迹的起点 $q_1$ 和终点 $q_n$ 在优化过程中是**固定的**。这体现在其有限差分矩阵 $K$ 和边界向量 $e$ 的设计上，导致其平滑度度量矩阵 $A = K^T K$ 的逆 $A^{-1}$ 的每一行，在终点位置会衰减到零。这意味着任何对终点的“修改意图”都会被 $A^{-1}$ 平滑掉，终点无法真正改变。
- **本文的改进**：为了能让终点移动，本文重新推导了 $K$ 和 $e$ ，将终点 $q_n$ 也视为变量。这样修改后的 $A^{-1}$ ，其最后一行（对应终点）不再衰减到零，而是变成一个常数值。**这一步是引入终点修正量的前置基础**。此时，无约束的 CHOMP 更新规则变为：
$\xi_{t+1} = \xi_t - \frac{1}{\eta_t} A^{-1}g_t$
这个公式已经允许终点移动了，但它没有任何目标约束，最终会为了追求平滑而缩回起点。

### 第二步：引入一般约束——将问题转化为“投影”

- **问题设定**：我们希望轨迹满足约束 $h(\xi) = 0$ 。为了将约束融入 CHOMP 的迭代框架，我们在每一步都求解一个带约束的二次近似问题：
$\begin{aligned}
\xi_{t+1} = \arg\min_{\xi} &\ g_t^T (\xi - \xi_t) + \frac{\eta_t}{2} \|\xi - \xi_t\|_A^2 \\
\text{s.t.} &\ h(\xi) = 0
\end{aligned}$
- **关键转化（等式9）**：通过配方，可以将目标函数改写。这个改写是推导的**第一个关键洞察**：
$\xi_{t+1} = \arg\min_{\xi} \|\xi_t - \frac{1}{\eta_t} A^{-1}g_t - \xi\|_A^2, \quad \text{s.t.} \ h(\xi) = 0$
这个公式的意义非常重大：它告诉我们，带约束的 CHOMP 更新，本质上就是**先走一个无约束步（得到** $\xi_t - \frac{1}{\eta_t} A^{-1}g_t$ **），然后将这个“无约束轨迹”在度量** $A$ **的意义下，投影到满足约束** $h(\xi)=0$ **的流形上**。

### 第三步：线性化求解——闭式解与修正量的诞生

- **线性化**：为了得到可计算的解，我们将约束 $h$ 在当前轨迹 $\xi_t$ 处线性化： $h(\xi) \approx C(\xi - \xi_t) + b = 0$ ，其中 $C$ 是雅可比矩阵， $b = h(\xi_t)$ 。
- **求解拉格朗日函数**：将线性化后的约束代入，构建拉格朗日函数并求解，得到最终的更新规则（公式11）：
$\xi = \underbrace{\xi_t - \frac{1}{\eta_t} A^{-1}g_t}_{\text{无约束步}} + \underbrace{\frac{1}{\eta_t} A^{-1}C^T(CA^{-1}C^T)^{-1}CA^{-1}g_t}_{\text{投影修正项}} - \underbrace{A^{-1}C^T(CA^{-1}C^T)^{-1}b}_{\text{偏移修正项}}$
- **识别修正量**：对比无约束步，后面的两项就是引入的“修正量”。它们共同作用，将无约束步拉回到线性化的约束面上。

### 第四步：特化到目标集——终点修正量的最终形式

- **特化**：对于目标集，约束只作用于终点，即 $h(\xi) = h_n(q_n)$ 。此时，雅可比矩阵 $C$ 只有最后一列非零： $C = [0, \ldots, 0, \tilde{C}]$ 。利用这个结构，并利用 $A^{-1}$ 最后一列 $B_n$ 的性质（特别是最后一行的 $B_{nn} = \beta I$ ），可以将复杂的公式11简化为公式14：
$\xi_{t+1} = \xi_t - \frac{1}{\eta_t} A^{-1}g_t + \frac{1}{\eta_t\beta} B_n^T \tilde{C}^T (\tilde{C}\tilde{C}^T)^{-1} \tilde{C} B_n g_t + \frac{1}{\beta} B_n \tilde{C}^T (\tilde{C}\tilde{C}^T)^{-1} b$
- **终点修正量的解读**：
    1. **终点处的无约束步**： $B_n g_t$ 是从整个轨迹的无约束步 $\frac{1}{\eta_t} A^{-1}g_t$ 中提取出来的、**针对终点的无约束修正量**。
    2. **终点处的投影**： $\tilde{C}^T (\tilde{C}\tilde{C}^T)^{-1} \tilde{C} (B_n g_t)$ 。这个算子将终点的无约束修正量投影到约束 $h_n(q_n)=0$ 的零空间上（在欧几里得度量下）。这就是**终点修正量在构型空间中的“投影”部分**。
    3. **终点处的偏移校正**： $\tilde{C}^T (\tilde{C}\tilde{C}^T)^{-1} b$ 是对当前终点不满足约束 ( $b \neq 0$ ) 的修正。
    4. **传播回整个轨迹**：最后，这个计算好的终点修正量通过 $\frac{1}{\beta} B_n^T$ 乘以前面的结果，**平滑地传播回整个轨迹**。由于 $B_n^T$ 的特性，这个传播是从起点（修正量为0）到终点（应用完整修正量）的线性插值。

---

### 2. 核心假设

这个推导过程依赖于以下几个关键假设：

1. **局部线性化**：假设在每个迭代步中，约束函数 $h(\xi)$ 可以在当前轨迹 $\xi_t$ 附近被线性函数 $C(\xi - \xi_t) + b = 0$ 很好地近似。这是大多数数值优化方法（如SQP）的基础，也是算法能够进行闭式求解的前提。对于高度非线性的约束，如果步长过大，线性化近似可能不准，导致收敛问题。
2. **凸近似**：在每一步迭代中，我们求解的是一个带线性约束的凸二次规划问题（目标函数是凸的二次型，约束是线性的）。这保证了该子问题有唯一的最优解。
3.  ****$CA^{-1}C^T$ **可逆**：为了保证投影算子存在，需要矩阵 $CA^{-1}C^T$ 是可逆的。这意味着约束必须是**线性无关的**。如果约束之间存在冗余，或者 $C$ 不是行满秩的，这个矩阵就是奇异的，需要特殊处理。

### 3. 核心洞察

本文最核心的洞察体现在两个层面：

1. **方法论层面：约束优化即“投影”**
将复杂的带约束轨迹优化问题，转化为一个非常直观的两步过程：**“先走无约束步，再投影回可行域”**。这个洞察来自对公式9的推导。它将抽象的数学优化与直观的几何图像联系起来，让算法的行为变得非常清晰易懂。论文中所有的后续推导和解释，都是在这个框架下进行的。
2. **目标集特化层面：投影的“降维”与“传播”**
当约束是目标集时，这个“投影”过程可以完美地分解为两个更简单的步骤：
    - **在“构型空间”进行欧几里得投影**：修正量的计算完全集中在终点上，并且在**构型空间**（而非任务空间）中使用**欧几里得度量**进行。这个结论是直接从数学推导中得出的，而不是凭直觉假设的。它揭示了为什么“在任务空间中投影末端执行器”这种看似合理的直觉是错误的——因为它使用了错误的度量。
    - **通过“平滑度量”进行传播**：终点修正量通过 $A^{-1}$ 的特性（即 $B_n^T$ ）平滑地反哺给整个轨迹。这完美地结合了 CHOMP 原有的核心优势（保持轨迹平滑），同时赋予了它处理目标集的新能力。

**总结一下，本文引入终点修正量的核心洞察就是：目标集约束下的轨迹优化问题，可以优雅地分解为“在构型空间用正确度量修正终点”和“用平滑算子传播修正”两个解耦的、直观的步骤。** 这个结论既有坚实的数学推导作为支撑，又有清晰的几何解释，并且在实际实验中证明了其有效性。
